Integração com Supabase

Opcional: sincronize o plano entre dispositivos. Configure seu projeto e crie a tabela com o SQL exibido abaixo. A chave usada aqui deve ser a chave pública anon/publishable, nunca a service_role.

Sincronização desligada. O plano continua salvo localmente.
SQL para criar a tabela e proteger os dados 
create table if not exists public.debt_plans (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.debt_plans enable row level security;
create policy "user can read own debt plan"
on public.debt_plans for select to authenticated
using (auth.uid() = user_id);
create policy "user can insert own debt plan"
on public.debt_plans for insert to authenticated
with check (auth.uid() = user_id);
create policy "user can update own debt plan"
on public.debt_plans for update to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

Execute esse SQL no SQL Editor do Supabase. Se a confirmação de e-mail estiver ativa, confirme o cadastro antes de entrar. A sincronização automática ocorre após salvar quando houver sessão ativa.
